# @pmndrs/timeline

Compose 3D behavior as a sequence of actions, concurrent activities, or a state graph. Run timelines from your application's frame loop.

```sh
npm install three @pmndrs/timeline
```

See the [vanilla Three.js tutorial](https://pmndrs.github.io/timeline/tutorials/7-vanilla) and the bundled [usage skill](skills/pmndrs-timeline/SKILL.md).
