# @react-three/timeline

Compose 3D behavior in React Three Fiber with generator timelines or JSX. This package connects timelines to component lifetimes and includes the @pmndrs/timeline core.

```sh
npm install three @react-three/fiber @react-three/timeline
```

See the [first timeline tutorial](https://pmndrs.github.io/timeline/getting-started/2-first-timeline) and the bundled [usage skill](skills/react-three-timeline/SKILL.md).
