# Timeline

Write composable 3D behaviors as stories: sequence actions, run them together, and switch between states.

- **@react-three/timeline** connects timelines to React Three Fiber through hooks and JSX.
- **@pmndrs/timeline** provides the core for Three.js applications with their own frame loop.

```sh
npm install three @react-three/fiber @react-three/timeline
```

For vanilla Three.js, install `three @pmndrs/timeline` instead.

See the [documentation](https://pmndrs.github.io/timeline/getting-started/1-what-is-a-timeline) for tutorials. Each published package includes its own usage skill under `skills/`.
